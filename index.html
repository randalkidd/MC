        GitHub storage — connect to save

        You're on a copy of the site that isn't the GitHub Pages address. Settings are stored per address, so use randalkidd.github.io/MC and enter the token there.

        Saving to the subdivision database, parcel reports and reviews commits files to your repo through GitHub's API. Simplest: store the token once in the Cloudflare relay (secrets GITHUB_TOKEN + SITE_KEY) and type only the passphrase in each browser.

        Or paste a GitHub token directly in this browser instead

        Relay (optional)

        County GIS usually answers this page directly. The EDMS septic search and Recorder don't allow cross-site requests, so they need a small relay. Deploy worker/cors-proxy.js to Cloudflare Workers (free) and paste its URL here.

        View relay code

        To update the relay: Copy relay code → Cloudflare → mc-relay → Edit code → select all, paste → Deploy.
