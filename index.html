Unofficial Maricopa County Zoning Hub

Look up any parcel in unincorporated Maricopa County. Each lookup shows its zoning, overlays, current and historic cases, plat setbacks, easements, floodplain, and section lines, all pulled live from public county records. The Reference tab has the Zoning Ordinance and Subdivision Regulation standards, all Planning & Development directives, and a searchable lookup of county codes and ordinances.

Staff tools (Plan review, Land division, SubdivisionDB and Saved Parcels) unlock after you connect. Go to ⚙ Settings, enter the relay URL and passphrase, click Save settings, then Test GitHub.

Runs the assessor record, every PlanNet layer (zoning, overlays, current and historic cases, districts, military), PLSS section lines and FEMA floodplain directly against county GIS, then fills the parcel-report template.

Read a site plan PDF

Pick the submittal type below, then drop the applicant's site plan here. Read plan (free) reads the PDF's own text in your browser (nothing is uploaded, no cost): APN, owner, address, lot area, zoning, scale, area table, coverage and labeled setbacks. It works on plans exported from CAD/Word, not on scans or hand drawings. If it can't read the plan, Read with Claude is offered: Claude reads every sheet, including scans and drawn dimensions, and fills the setbacks, structures and checklist (sent through your relay to Anthropic, read once and deleted; billed to your API key). Either way, the APN, owner, address, lot area, zoning and subdivision/lot are checked against the Assessor record and the recorded deed. Verify every value against the plan.

        GitHub storage — connect to save

        You're on a copy of the site that isn't the GitHub Pages address. Settings are stored per address, so use randalkidd.github.io/MC and enter the token there.

        Saving to the subdivision database, parcel reports and reviews commits files to your repo through GitHub's API. Simplest: store the token once in the Cloudflare relay (secrets GITHUB_TOKEN + SITE_KEY) and type only the passphrase in each browser.

        Or paste a GitHub token directly in this browser instead

        Relay (optional)

        County GIS usually answers this page directly. The EDMS septic search and Recorder don't allow cross-site requests, so they need a small relay. Deploy worker/cors-proxy.js to Cloudflare Workers (free) and paste its URL here.

        View relay code

        To update the relay: Copy relay code → Cloudflare → mc-relay → Edit code → select all, paste → Deploy.
