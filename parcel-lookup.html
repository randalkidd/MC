Parcel Lookup

Enter a Maricopa County parcel number (APN) to pull Assessor, zoning, overlay, case, floodplain and deed records live from the county's own GIS services.

This preview can't reach county servers. Claude's artifact preview only allows network requests to a small set of code-library hosts, so the live gis.maricopa.gov queries this page needs are blocked here with no server ever being contacted. Download the HTML file and open it directly in your own browser (double-click it, or drag it into a browser tab) — outside this preview, nothing blocks the request, and Maricopa County's GIS services already allow cross-site access.
